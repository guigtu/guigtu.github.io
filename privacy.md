# Politique de confidentialité de n8n agents

Dernière mise à jour : 15 novembre 2026.

n8n agents est une application personnelle, utilisée uniquement par son propriétaire sur son propre compte Google. Elle n'a pas d'autres utilisateurs.

Données consultées : avec l'autorisation explicite du propriétaire, l'application peut lire les e-mails de son compte Gmail, créer des brouillons et, si elle y est autorisée, consulter son agenda et ses fichiers Google Drive.

Utilisation des données : ces données servent uniquement à fournir au propriétaire des résumés, des classements et des brouillons de réponse. Elles ne sont ni vendues, ni partagées avec des tiers, ni utilisées à des fins publicitaires.

Traitement : les données sont traitées sur un serveur privé hébergé dans l'Union européenne. Des extraits peuvent être transmis à l'API d'un modèle de langage pour générer les résumés et brouillons demandés par le propriétaire.

Conformité Google : l'utilisation des informations reçues des API Google respecte les règles relatives aux données utilisateur des services API Google, y compris les exigences d'utilisation limitée.

Révocation : l'accès peut être retiré à tout moment depuis la page Autorisations du compte Google.

Contact : via le profil GitHub guigtu.
